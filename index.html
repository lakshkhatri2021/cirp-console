How the AI detector works

Isolation Forest

Detection rules only fire when a metric crosses a fixed threshold, and those thresholds sit far above normal so that noise never trips them. A resource can therefore be clearly unhealthy without any rule firing. The AI detector learns what normal looks like for each resource and flags readings that do not fit.

  1. Normalise the last 5 readings with the resource's learned mean and spread.
  2. Build three features: the current level, the window median and the window minimum.
  3. Score them with an Isolation Forest of 100 trees trained only on healthy telemetry.
  4. Raise an incident when the score stays above the threshold for 4 readings in a row and no rule has already raised one.
