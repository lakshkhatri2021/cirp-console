# CIRP Operations Console

Live demo of the operations console from the Cloud Incident Response and Infrastructure Monitoring Platform
(BCSE301P Software Engineering lab project, VIT Vellore: Aiman Dhanani, Laksh Khatri, Aman Golani).

The page runs entirely in the browser: `engine.js` is a port of the Python backend and `model.json` is the
trained Isolation Forest used for AI anomaly detection. Sign in as System Administrator to inject faults.
